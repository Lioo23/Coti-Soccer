# Coti Soccer

Jugá en el navegador: [https://lioo23.github.io/Coti-Soccer/](https://lioo23.github.io/Coti-Soccer/)

## Controles

- **1 jugador vs CPU**
- **2 jugadores en la misma PC**
  - Jugador 1: `A`/`D` para mover, `W` para saltar, `S`/`F`/Espacio para patear
  - Jugador 2: flechas para mover, abajo/`L`/Enter para patear
- **Modo online** con código de sala
